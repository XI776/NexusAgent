# 演示场景故障排查手册

本文档只用于测试知识库上传和检索，场景为虚构商城。

## 登录失败

1. 记录页面显示的错误信息，不要收集用户密码或验证码。
2. 检查网络是否可用，并确认账号输入无误。
3. 如果提示凭据无效，引导用户走官方密码重置流程。
4. 如果提示权限不足，联系管理员核对角色配置。

## 订单查询异常

1. 核对订单号和登录账号是否对应。
2. 检查订单页面是否有维护或同步提示。
3. 无法确认订单状态时，转交人工客服核验，不要推测支付结果。

## 支付或退款争议

先核对订单号与支付流水；涉及扣款、退款和补偿时交由人工处理。不得承诺未经核验的到账时间或处理结果。
